# prateekvishnu.github.io

Personal site for Vishnu Kakaraparthi. Plain static HTML/CSS/JS, no build step.

- `index.html` — the page
- `styles.css` — all styles (light/dark via `data-theme`)
- `script.js` — theme toggle, mobile nav, accordion
- `assets/headshot.png`, `assets/Vishnu_Kakaraparthi_CV.pdf`
- `googlecda3cbed3f1fb273.html` — Google Search Console verification, keep

To update content, edit `index.html` directly and push to `main`.
